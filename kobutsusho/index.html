Scope — このマニュアルの想定

こういう人を想定しています

日本国内に住む個人が、自宅を営業所として、フリマアプリで「仕入れ → 出品 → 販売 → 再仕入れ」を繰り返すケースです。

  1. 仕入れる：フリマアプリなどで中古品を買う
  2. 整える：自宅で保管・検品して出品作業をする
  3. 売る：フリマアプリ・オークションサイトなどで販売する
  4. 回す：売上を元手にまた仕入れる
居住地日本国内
事業者区分個人（法人ではない）
仕入れ先主にフリマアプリ・ネット上の中古品
販売先フリマアプリ・オークションサイトなど
営業所自宅を「主たる営業所」として使用
管理者本人が兼任（単独運営）
Note 自分の不用品を処分するだけで、継続的な仕入れ販売をしないなら、許可が不要な場合があります。迷ったら申請前に管轄警察署へ相談を。

Ch.1 — Definition

そもそも古物商許可とは

中古品を継続的に仕入れて販売する行為を「業として」行うために必要な、都道府県公安委員会の許可です。フリマアプリで中古品を仕入れてフリマアプリなどで売る行為は、原則としてこの許可の対象になります。

許可が不要になる可能性がある例

  • 自分の不用品の処分だけ（仕入れを伴わず、私物を売るのみ）
  • 無償で譲り受けた物だけを販売する（対価を払って仕入れていない）
  • 海外から輸入した新品のみを扱う（中古品の売買にあたらない）
Caution 上はあくまで目安です。「継続性」「営利性」の判断は個別具体的。続けて売る予定があるなら、営業を始める前に要否を管轄警察署の生活安全課へ確認してください。

Ch.1 — Preparation

STEP 01

営業所を決める

「主たる営業所」を先に決めると管轄警察署が確定し、そこから全ての手続きが動き出します。

自宅を営業所にする場合、この6つが自宅で完結するか

  1. 仕入れた古物の保管（売却まで安全に置けるスペース）
  2. 古物の検品・撮影（状態確認・写真・簡単な清掃）
  3. フリマアプリでの出品作業（PC・スマホで商品説明を作成）
  4. 購入者との連絡・問い合わせ対応
  5. 梱包・発送作業（資材の保管、発送手配）
  6. 帳簿（取引記録）の保管

自宅を営業所にできるか

  • 自分名義または家族名義の物件である
  • 賃貸なら、契約書に「事業利用可」の条項があるか確認済み
  • 集合住宅なら、管理規約に反しないか確認済み
  • 商品の保管場所を、生活空間と区切って確保できる
  • 「使用権限を示す資料」が必要か、警察署に確認する
Caution 賃貸・分譲マンションは、契約書や管理規約で事業利用が禁止されていないか必ず事前確認を。無断で営業所にすると契約違反になる可能性があります。

Ch.1 — Preparation

STEP 02

管轄の警察署を調べる

申請先は「主たる営業所を管轄する警察署」。担当は通常、生活安全課などです。自宅所在地ではなく営業所の所在地で判定される点に注意。

調べ方の目安

  1. 各都道府県警察の公式サイトで「古物商許可」ページを検索
  2. 「管轄区域一覧」で自宅住所を含む警察署名を確認
  3. 電話番号・生活安全課の受付曜日／時間を控える

警察署について確認する6項目

  • 警察署の正式名称（申請書に記載するため正確に）
  • 担当課・担当係の名称（生活安全課 防犯係 など）
  • 直通電話番号（代表ではなく担当課へ直通のもの）
  • 受付曜日・時間（平日のみ／時間帯限定が多い）
  • 事前予約の要否
  • 手数料の納付方法・必要書類の部数

Ch.2 — Documents

必要書類の全体像（7種類）

個人が自宅を営業所とする一般的なケースで必要になる書類です。

01

古物商許可申請書

所定様式。氏名・住所・営業所・扱う古物区分などを記入する中心書類。

02

略歴書

最近5年間の職歴などを空白期間なく時系列で記載。本人と（選任時は）管理者の分。

03

住民票

本籍記載のもの。外国籍は国籍等記載のもの。個人番号は原則不要。

04

誓約書

古物営業法上の欠格事由に該当しないことを誓約する所定様式。

05

身分証明書

本籍地の市区町村が発行する公的書類。運転免許証やマイナンバーカードではない。

06

管理者関係書類

本人以外を管理者にする場合、その人の略歴書・住民票・身分証明書・誓約書。

07

URL関係資料

独自ドメインHPやモール店舗などURLを届け出る場合、使用権限を示す資料。

Note 住民票と身分証明書は発行から3か月以内のもの。複数枚必要な書類は同じ内容で用意。迷う欄は空欄のまま警察署に相談を。

Ch.2 — Doc 01 / 住民票

住民票を取得する

住民登録している市区町村役場、または対応自治体ならコンビニ交付で取得します。

  1. 「本籍記載」は必須：交付申請書の「本籍の記載」欄にチェック。記載なしは受理されません。
  2. 外国籍の方は「国籍等」記載のもの：在留資格・在留期間等が記載されたもの。窓口で明確に伝える。
  3. 「個人番号」記載は原則不要：誤って記載付きを取らないよう「個人番号なし」を窓口で明示。

取得時に確認する5項目

  • 「本籍」が記載されている
  • 氏名・住所・生年月日が申請書と一致している
  • 個人番号（マイナンバー）は記載されていない
  • 外国籍の方は「国籍等・在留資格」が記載されている
  • 申請日時点で発行から3か月以内である

Ch.2 — Doc 02 / 身分証明書 ★重要

「身分証明書」の落とし穴

Attention ここでいう「身分証明書」は、運転免許証やマイナンバーカードのことではありません。

正体は、本籍地の市区町村が発行する公的な証明書類です。「破産手続開始の決定を受けて復権を得ない者ではないこと」「後見登記等ファイルに記録がないこと」などを証明します。

これは違う運転免許証・マイナンバーカード
これが必要本籍地の市区町村発行の「身分証明書」

取得時のチェック4項目

  • 本籍地の市区町村で取得している（住民票の住所ではない）
  • 「破産手続開始の決定を受けて復権を得ない者ではない」旨の記載がある
  • 本籍地 ≠ 現住所なら、郵送請求・代理取得の方法を確認済み
  • 申請日時点で発行から3か月以内である
Point 本籍地が遠方なら、郵送請求のリードタイム（1〜2週間程度）を見越して早めに手配を。

Ch.2 — Doc 03 / 略歴書

略歴書を作成する

最近5年間を、空白期間なしで記載します。会社員／自営業／主婦（主夫）／学生／無職／求職中も、そのまま事実として書けば大丈夫です。

期間職歴・所属など
R3.4 – R5.3株式会社○○ 会社員
R5.4 – R6.8パート勤務
R6.9 – R7.3無職
R7.4 – 現在個人事業（物販準備）

チェック5項目

  • 最近5年間分をカバーしている
  • 時系列に並び、空白期間が一切ない
  • 無職・求職中も事実どおり記載
  • 住所・氏名・生年月日が住民票と一致
  • 末尾に作成日・署名（押印の要否は都度確認）

※ 別に管理者を選任する場合は、その方の略歴書も別途必要です。

Ch.2 — Doc 04–05 / 誓約書 & 管理者

誓約書と管理者を決める

自宅を営業所として本人が管理者を兼任するなら、本人の誓約書と略歴書だけで足りるのが一般的です。

誓約書

  • 申請書と一緒に配布される所定様式を使う
  • 氏名・住所は住民票と完全一致で記入
  • 「本人用」「管理者用」の2種類があり得るため警察署に確認
  • 日付は空欄で持参し、窓口で確認しながら記入が安全

管理者を決める

  • 自宅を営業所＆本人が業務するなら「本人＝管理者」で可
  • 本人以外を管理者にするなら、その人の書類が別途必要（住民票／身分証明書／略歴書／誓約書）
  • 管理者は営業所で実際に業務を統括できる人（常勤性に注意）
  • 欠格事由（未成年／破産・復権未取得／一定の前科ありなど）に該当しない

Ch.2 — Internet

インターネット取引の扱い

取引形態によってURL届出の要否や必要書類が変わります。次の5パターンを整理して、電話で確認しましょう。

フリマアプリ通常アカウント／独自ドメインHP／ネットショップ／モール店舗ページ／事業者向けショップ機能

フリマアプリの通常アカウントで個人として販売する場合、そのアカウントのURLや店舗ページの届出は必要でしょうか。また、将来フリマアプリの事業者向けショップ機能を使う場合や、独自ドメインの販売ページを設ける場合のURL関係の書類についても教えてください。

URL使用権限を示す資料の例

  • プロバイダ発行の登録通知書のコピー（申請者名義でドメイン契約している旨）
  • ドメイン登録情報のプリントアウト（登録者名・登録日・有効期限）
  • WHOIS検索結果のプリントアウト（申請者＝登録者であること）
  • その他、登録者名等が確認できる資料（レジストラ管理画面のスクショ 等）

Ch.3 — Application

申請書を記入してセルフチェック

誤字・記入漏れが差戻しの主な原因です。揃ったら記入とチェックを。

申請書の主な記載項目（11個）

  • 氏名・住所・電話番号
  • 生年月日・本籍
  • 主たる営業所の所在地
  • 営業所の名称
  • 取り扱う古物の区分（複数可）
  • 主として取り扱う古物区分（1つ）
  • 管理者の氏名・住所
  • 行商（古物市場・出張買取など）の有無
  • ホームページ・URL利用の有無
  • 届出するURL（独自ドメイン等）
  • 申請日・署名（押印は都度確認）

提出書類チェック

  • 申請書（記入・署名済）
  • 略歴書（最近5年間／空白なし）
  • 住民票（本籍記載／3か月以内）
  • 誓約書（所定様式）
  • 身分証明書（本籍地市区町村発行／3か月以内）
  • 管理者用書類（別人選任の場合）
  • URL関係資料（独自ドメイン届出時）
  • 使用権限資料（自宅・営業所）※要否は要確認
Tip 迷う欄は空欄のまま持参し、窓口で相談するのが最も安全。自己判断で書いた誤情報は差戻しの主因になります。

Ch.3 — Submit & Review

警察署へ申請 → 審査

揃ったら管轄警察署に予約（必要な場合）し、生活安全課の窓口で申請します。

¥19,000 申請手数料（納付方法は都道府県で異なる／収入証紙・現金など。事前確認は必須）

申請日の持ち物（7点）

  • 必要書類一式（予備に1部コピーがあると安心）
  • 申請手数料 19,000円（納付方法に応じた形式で）
  • 本人確認書類（運転免許証・マイナンバーカード等）
  • 印鑑（認印可／押印の要否は事前確認）
  • 筆記用具（消せないボールペン）
  • 受付曜日・時間内、必要なら事前予約完了済み
  • 許可証を受け取るまで営業しない、と理解している
Important 申請した時点ではまだ未許可です。許可証を受け取るまで、営業を開始してはいけません。

Ch.4 — After License

許可はゴールではなくスタート

許可後は、継続する3つの義務があります。

義務1 ・ 仕入れ記録を残す

  • 取引年月日／古物の種類・数量／特徴（型番・状態など）
  • 相手方の住所・氏名・職業・年齢
  • 仕入れ価格／仕入れ先サービス名（フリマアプリ名等）
  • 取引画面の資料（スクリーンショット等）

義務2 ・ 取引相手を確認する

  • 相手方の住所・氏名・職業・年齢を確認
  • 確認方法は住所地宛の送付／本人確認書類の提示／電子的な本人確認 など
  • フリマアプリで買い受ける場合も確認義務が原則適用される
  • 確認方法・記録の取り方は必ず警察署に確認

義務3 ・ 帳簿を管理する

  • 古物営業法に基づく所定様式の帳簿を用意（データ管理も可）
  • 仕入れ・販売の両方を記録
  • 後から確認できる状態で保管（方法・期間は管轄警察署の指示に従う）
Caution フリマアプリの本人確認機能だけで、古物営業法上の確認義務を満たすとは限りません。運用は必ず警察署に確認を。

Ch.4 — Record Flow

記録の抜けが起きにくいオペレーション例

仕入れ側

  1. フリマアプリで購入（取引画面のスクショ取得）
  2. 帳簿に記録（取引年月日／商品／相手方／価格／アプリ名）
  3. スクショを商品IDと対応づけて保存
  4. 商品到着 → 検品（写真・状態記録）
  5. 特徴・状態を確認し帳簿の補足欄に追記

販売側

  1. フリマアプリに出品（商品ID発行／出品画面保存）
  2. 売れた瞬間、購入者情報を記録（住所・氏名・取引画面）
  3. 帳簿に販売記録（取引年月日・販売価格・相手方）
  4. 梱包・発送（発送控え・追跡番号を記録）
  5. 売上・手数料を記録し、次の仕入れ資金へ反映

Appendix — Prefecture-specific

都道府県で運用が異なる8項目

ここは全国一律に断定できません。必ず管轄警察署に事前確認を。

  • 自宅を営業所にできるか／追加資料（間取り図・写真など）の要否
  • 営業所の使用権限を示す資料（契約書・使用承諾書など）の要否と種類
  • 古物区分の選び方／「主として扱う」区分の運用
  • 行商の要否・記載方法
  • フリマアプリ利用時の記載方法（アカウントURL・ショップページ）
  • URL届出の要否＆使用権限資料
  • 必要書類の部数／手数料の納付方法（収入証紙・現金・電子納付）
  • 取引相手の本人確認方法の運用（電子的確認の可否）

Summary — 8 Steps

全体を8ステップで振り返る

  1. 営業所を決める（自宅で6機能が完結する）
  2. 管轄警察署を調べる（生活安全課／受付時間）
  3. 警察署へ電話（12項目を確認）
  4. 書類を集める（住民票／身分証明書／略歴書 ほか）
  5. 申請書を記入（古物区分／URL／行商を確定）
  6. 警察署に申請（手数料 19,000円 納付）
  7. 審査 → 許可証受取（受け取るまで営業しない）
  8. 仕入れ／販売／帳簿を運用（記録・確認・保管を継続）

まずは、営業所を管轄する警察署へ電話することから。一歩ずつ進めれば、フリマアプリを軸にした中古品販売を安心して始められます。
